# ワークアウト用音楽ジェネレーター

`workout_music.py` は、外部の音源素材や有料APIを使わずに numpy / scipy だけで
EDM 系のワークアウト用トラックを合成するスクリプトです。生成した曲は自作音源なので、著作権を気にせず使えます。

## 曲の構成

| パート | 内容 |
|---|---|
| ウォームアップ (16小節) | キック + パッド。フィルターが徐々に開いていく |
| ビルドアップ (8小節) | アルペジオ + ライザー + スネアロールで盛り上げる |
| ドロップ (32小節) | キック・ベース・コードスタブで全力パート |
| ブレイク (16小節) | キックが抜けて呼吸を整える区間 |
| クールダウン (16小節) | 音を減らしてフェードアウト |

ビルドアップ → ドロップ → ブレイク を `--drops` の回数だけ繰り返すので、インターバルトレーニングにも使えます。

## 使い方

```bash
pip install numpy scipy        # MP3 出力には ffmpeg も必要
python workout_music.py                                  # 128BPM / Aマイナー / 約4分
python workout_music.py --bpm 150 --key D --drops 3      # ランニング向け 約5分
python workout_music.py --bpm 105 --drops 1              # ウォーキング・ストレッチ向け
```

| オプション | 説明 | 既定値 |
|---|---|---|
| `--bpm` | テンポ (目安: ウォーキング 100-120 / 筋トレ 120-140 / ランニング 150-170) | 128 |
| `--key` | マイナーキーの主音 (C, C#, D … B) | A |
| `--drops` | 高強度パートの回数 | 2 |
| `--seed` | 音色の揺らぎを変える乱数シード | 1 |
| `--out` | 出力フォルダ | output |

`output/` に WAV と MP3 (192kbps) が書き出されます。WAV はサイズが大きいため Git 管理外です。

## 収録済みサンプル

- `output/workout_128bpm_Am.mp3` — 筋トレ・サーキット向け (約4分, ドロップ2回)
- `output/workout_150bpm_Dm.mp3` — ランニング向け (約5分, ドロップ3回)
